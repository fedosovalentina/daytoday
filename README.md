# DAY Today Plan

A one-page habit planner. The day, the week, and the month sit on a sheet of graph paper, so the list for today is always in your hand.

The name on the phone is DAY Today Plan. The project and the bundle id stay `daytoday` / `com.fedosovalentina.daytoday`. The interface follows the phone language: English, Dutch, Russian, German, French, Spanish, Portuguese, Arabic (right to left), Chinese, Korean, Hindi, and Japanese. The product name is the same in every language. Habits and their history stay on the phone.

```bash
flutter pub get
flutter run
```

The first launch plants five sample habits and a few weeks of history, saved on the phone. There is no account. Archive hides a habit and keeps its history.

Type is [Shantell Sans](https://github.com/arrowtype/shantell-sans), used under the SIL Open Font License (`assets/fonts/OFL.txt`).
